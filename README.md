# Origami Interactive Website

A portfolio site for my origami tessellations, built while learning web development from scratch.

## What's here

- `lessons/` – small practice pages, one web concept each (HTML, then CSS, JavaScript, and SVG for crease patterns). Open any `.html` file by double-clicking it; it runs in your browser with nothing to install.

## Where it's going

1. An interactive gallery of my tessellations.
2. A tool that draws crease patterns for tessellations (starting with a grid-based twist-fold generator).
3. A documented catalog of fold sequences.
